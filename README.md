# Kaiwen Yang · Personal Portfolio

A Chinese–English portfolio of websites and little games. All five featured projects were created independently by Kaiwen Yang.

## Featured projects

- [LatinoPedia](https://kaiw-yang.github.io/latinopedia/#home) — A Latin American studies gateway for Chinese-speaking learners.
- [Iberia](https://katia317.github.io/iberia-study/#/) — Dictionary lookup, vocabulary review, and DELE preparation.
- [CSOPedia](https://csopedia.katiaovelha.chatgpt.site/) — An unofficial Independent Service Coordination reference.
- [Pixel Monsters / 像素小怪兽](https://pixel-pet-three.vercel.app/) — A multilingual pixel monster game.
- [Stall Anywhere / 摆到世界尽头](https://stall-anywhere.vercel.app/) — A street-stall game in snowy Nordic mountains.

## Features

Chinese/English language switching, project filters, live project screenshots, detailed project notes, and responsive layouts. Built with plain HTML, CSS, and JavaScript; no build step is required.

## GitHub Pages

Publish the `main` branch from `/ (root)` in Settings → Pages. All asset references are relative so the site also works under a repository subpath.

## Local preview

Run `python3 -m http.server 4173` in this directory, then open `http://localhost:4173`.

## Files

- `index.html`: Homepage and bilingual introduction.
- `projects.js`: Bilingual project content and links.
- `app.js`: Language switching, filters, and project details.
- `style.css`: Responsive styles.
- `assets/`: Screenshots of the featured projects and the site icon.
